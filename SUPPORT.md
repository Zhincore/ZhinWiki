# Support

ZhinWiki is maintained in public. Use the channel that matches the kind of help
you need:

- Ask setup and usage questions in [GitHub Discussions](https://github.com/Zhincore/ZhinWiki/discussions).
- Report reproducible bugs with the [bug report template](https://github.com/Zhincore/ZhinWiki/issues/new?template=bug_report.yml).
- Propose features with the [feature request template](https://github.com/Zhincore/ZhinWiki/issues/new?template=feature_request.yml).
- Read the [production checklist](docs/self-hosting/production.mdx) before operating ZhinWiki in production.

Support is best-effort. The project does not currently promise response or
resolution times for public support requests.

Do not post credentials, private logs, or customer content in an issue or
discussion.
